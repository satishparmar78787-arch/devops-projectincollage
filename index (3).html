CI/CD Pipeline

From git push to production in minutes, with zero manual steps.

  1. 1

    Code Push

    Developer pushes code to GitHub. The workflow triggers automatically.

  2. 2

    Build & Test

    GitHub Actions checks the code and builds the Docker image.

  3. 3

    Security Scan

    Trivy scans the image for known vulnerabilities.

  4. 4

    Push to Registry

    The tagged image is pushed to Docker Hub.

  5. 5

    Deploy

    Kubernetes (k3s) on AWS EC2 rolls out the new version with no downtime.

  6. 6

    Monitor

    Prometheus and Grafana track CPU, memory and pod health.
